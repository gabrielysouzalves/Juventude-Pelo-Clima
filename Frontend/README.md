# Juventude Pelo Clima

Plataforma web do projeto **Juventude pelo Clima**, desenvolvida com **React, Spring Boot e Oracle** para gerenciamento de participantes, inscrições e ações de conscientização ambiental e sustentabilidade.

## Tecnologias

* React
* Vite
* Spring Boot
* Oracle Database
* React Router DOM
* React Icons

## Objetivo

O sistema foi criado para apoiar iniciativas de educação ambiental, engajamento juvenil e organização de eventos e atividades sustentáveis do projeto **Juventude pelo Clima**.

## Como executar o frontend

```bash
npm install
npm run dev
```

A aplicação ficará disponível em:

```text
http://localhost:5173
```
